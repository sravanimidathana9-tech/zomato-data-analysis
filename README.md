# Zomato Data Analysis

Exploratory data analysis of the Zomato Bangalore dataset (51,717 restaurants, 17 columns) using Python, Pandas, NumPy, Matplotlib and Seaborn.

## What I did
- Converted text ratings (e.g. 4.1/5) to numeric values and handled "NEW" and missing ratings
- Removed 10,052 unrated rows, leaving 41,665 rated restaurants
- Built charts for restaurant types, votes by type and online-order availability

## Key findings
- Average rating is 3.7 out of 5
- Most-voted restaurant: Byg Brewski Brewing Company (16,832 votes)
